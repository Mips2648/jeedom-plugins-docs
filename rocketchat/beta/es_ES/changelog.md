## 2022-10-17

- Actualización de la presentación de los comandos para Jeedom v4.3

## 2022-09-19

- Se ha añadido una opción para enviar archivos locales directamente desde un escenario; consulta la documentación.

## 2022-05-17

- Cambio de la API utilizada para el envío de mensajes con el fin de solucionar el problema de la fecha incorrecta (mensajes enviados con fecha del 1/01/1979)

## 2022-03-28

- Compatibilidad con Rocket.Chat v4
- Esta actualización requiere reinstalar las dependencias; esto debería realizarse automáticamente al actualizar el complemento.
- Incorporación de la visualización en formato de tabla de la lista de equipos para Jeedom 4.2
- Se ha eliminado la compatibilidad con Debian Stretch; a partir de ahora es imprescindible utilizar, como mínimo, Debian Buster.

## 2020-12-02

- Se ha añadido la compatibilidad con botones para responder rápidamente a las preguntas (tipo Telegram)
- Nueva presentación de la lista de objetos
- Mejora del diseño de la configuración de los equipos y los controles
- Revisión del diseño para la versión 4

## 2020-08-15

- Fuerza la configuración de la clave API en modo localhost

## 2020-03-30

- Traslado de la documentación

## 2020-03-27

- Se ha cambiado el método de envío de mensajes, ya que el anterior provocaba que la aplicación Rocket.Chat para Android se colgara en determinadas situaciones (debido a un error en la API de Rocket.Chat).

## 2020-03-20

- Ya no es necesario mencionar al bot en las interacciones de una conversación directa o un mensaje privado.
- Comprobación de la configuración antes de iniciar el demonio
- Comprobación del estado del demonio antes de utilizar un comando

## 2020-02-14

- Se ha añadido la compatibilidad con archivos adjuntos (por ejemplo, imágenes de las cámaras)

Primera versión
